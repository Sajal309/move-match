# Bundled model asset

`pose_landmarker_lite.task` is the Google MediaPipe Pose Landmarker Lite Float16 bundle used by the native iOS and Android implementations. Its SHA-256, upstream URL, version and license are recorded in `model-manifest.json`.

From the workspace root, run `pnpm model:fetch` to retrieve the official asset and verify it against `assets/models/model-manifest.json` before replacing the bundled file.
